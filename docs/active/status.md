# 当前状态与公开路线

> 更新：2026-11-26。本文只记录可公开披露的产品状态，不包含内部测试地址、账号、提交记录或本机路径。

## 当前阶段

- 版本仍按 **0.3.1 整改期**管理，尚未封版；不制作离线包、不修改版本号。
- 产品主线是 **AI-first 新手任务闭环**，不是继续横向堆接口、菜单和报告。
- 公开仓库目前是工程预览，不是已经完成全部验收的正式发布版本。
- 真实云只读任务、真实账单对账和目标用户走查仍在验收条件之外；页面渲染、接口 200 或 mock 通过都不能替代这些验证。

   - 在明确授权的账号、地域和权限范围内执行真实只读云任务；

## 数据库：唯一支持 PostgreSQL

- 后端 `DATABASE_URL` 只接受 PostgreSQL，启动即拒绝 SQLite。
- 目标 PostgreSQL 为空库且安装目录存在旧 `qianshu.db` 时拒绝启动，避免静默建空库。
- Compose 默认使用栈内 PostgreSQL 16；源码安装默认安装 PostgreSQL 15，或通过显式 `DATABASE_URL` 接外部 PostgreSQL。
- SQLite 已废除，不提供旧数据迁移；备份固定使用 `pg_dump -Fc`。
- 已在一次性 PostgreSQL 16 环境验证测试库工厂、主库 mock/冒烟测试、E2E 冒烟和备份恢复；干净主机上的完整安装器与真实远端 CI 仍未验证。

## 已保留的产品切片

1. **统一首次接入**：安装向导、云账号后台、智能体和同步任务共享 Onboarding Run 与真实就绪证据。
2. **限定真实 SLS 验证**：在授权只读范围内完成目录、样本、角色、采纳、统一检索和第一次巡检价值验证；未知角色和失败项仍保留。
3. **可解释业务归属**：自动结果只形成 draft，人工逐条确认后才进入归属消费通道。
4. **模型主动只读走查**：模型可选择受控 API/浏览器动作，并通过内容断言和独立回放验证。
5. **行为画像上下文**：进程或 URL 变化结合同窗口资源影响判断，缺证据保持待核实。
6. **通用变更源**：拉取 adapter 与持久化解耦，ActionTrail 是内置实现之一，webhook 仍是推送模型。
7. **平台内问题自愈**：错误统一进入问题收件箱，先做只读诊断和结构化计划；R0/R1 可在 `auto_r0` 下自动执行，R2/R3 需管理员按计划哈希授权，命令/主机/平台外写/外部通知/删库一律禁止。默认 `observe` 模式只记录。

各项能力的证据等级和不能推断的范围见 [capabilities.md](capabilities.md)。

## 成本能力边界

- 费用拆解、成本异动、资源包预测和采购量粗算保留。
- 购买登记、核价/净节省、买后复盘及整套账号隔离改造暂停。
- 成本洞察只读本地已采集账单；GET 不触发云同步、外部写入、通知或异常生命周期变更；不提供采购、SKU 或确定节省金额建议。

## 明确不做

- 不执行云侧写、创建索引、外部集群写或真实通知。
- 不自动确认、合并或删除真实业务映射，不自动购买资源包。
- 不将原始日志持久化或发送外部模型，不用名称相似度猜业务。
- 未经人工核对不公开或固化视觉基线。
